
Care Express is a mobile application dealing with health and medicine which is built using React Native and Firebase.  
It connects patients with doctors, allows searching for medicines, viewing recommendations, chatting, and handling user profiles.  

#Our features are:
- User Authentication (Patient & Doctor)
- Patient & Doctor dashboards
- Doctor can view registered patients and give recommendations
- Real-time chat between doctors and patients
- Medicine search via FDA API
- Checkout & payment screen (card details)
- Persistent login
- Logout functionality
- Profile management for users

## Our screens include:
- Splash Screen
- Login / Register
- Patient Tabs: Home, Search, Notifications, Chat, Profile
- Doctor Tabs: Dashboard, Patients, Recommend, Profile
- Checkout Screen
- Recommendation Screen
- View Patients Screen
- Individual Chat Screen

## Technologies Used are:
- React Native
- Firebase Authentication & Realtime Database
- React Navigation (Stack & Bottom Tabs)
- Axios (for API requests)
- Expo or React Native CLI
